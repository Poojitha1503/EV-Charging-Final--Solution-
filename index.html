▦ Target Architecture Blueprint FOUR CONNECTED LAYERS

Business Architecture

Receive candidate → review information → evaluate suitability → compare sites → make decision → document reasons.

Application Architecture

CSV data loader → site analysis → scoring engine → ranking & comparison → dashboard interface → decision recording.

Data Architecture

Candidate sites, EV registrations, traffic, competition, amenities, lease and installation costs, calculated scores, recorded decisions.

Technology Architecture

R-generated synthetic CSV → HTML/CSS interface + JavaScript + Chart.js → GitHub source control → GitHub Pages hosting → web browser.

Prototype scope: static hosting, local browser decision storage, CSV exports. No shared database, live charging API, authentication or server-side persistence.
